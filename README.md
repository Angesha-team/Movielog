\# Movielog



\## Опис проєкту

Movielog — це програма для ведення особистого списку фільмів, створена мовою C++.



\## Основні можливості

\- Додавання фільмів.

\- Перегляд списку фільмів.

\- Редагування інформації.

\- Видалення фільмів.

\- Пошук фільмів.



\## Використані технології

\- C++

\- Visual Studio

\- Git

\- GitHub
